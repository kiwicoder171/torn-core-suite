## 3. Mandatory Anti-Slop Enforcers
- 🚫 **Banned Elements**: canvas particles, starfields, emojis as icons, neon halos, Cinzel font
- 🚫 **Iconography Rule**: Never use system emojis as functional or navigation icons. Use clean Lucide/Radix SVGs or crisp typographic labels.
- 🚫 **Layout Rule**: Zero Day-0 feature bloat. Perfect the single core interaction before adding secondary panels.
- 🎨 **Visual Taste Gate**: Every UI milestone requires a visual verification check against these tokens before marking `DONE`.
